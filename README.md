# toz-app

Application web légère en **React + Vite**, déployée sur GitHub Pages.

Structure volontairement simple : composants, données et utilitaires séparés,
pour rester facile à faire évoluer.

## Stack

- **React** 18
- **Vite**
- **lucide-react** — icônes
- **heroicons** — icônes

## Démarrage

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```
